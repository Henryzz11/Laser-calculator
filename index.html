Derivation

This derivation uses 1/e2 Gaussian beam diameters. First convert the measurable diameters into radii:

wL = D2 , w0 = d2

The lens maps the input beam radius into a focusing cone. For a small half-angle, the geometric angle is approximately

θ = wLf

The diffraction-limited Gaussian half-angle is

θ = M2 λπ w0

Both expressions describe the same focusing half-angle, so set them equal:

wLf = M2 λπ w0

Solving for the focused beam radius gives

w0 = M2 λ fπ wL

Replace the radii with the corresponding diameters:

d2 = M2 λ f π · D2

Multiplying both sides by 2 gives the diameter form:

d = 4 M2 λ fπ D ≈ 1.27 M2 λ fD

The factor 1.27 is the rounded engineering form of 4 over π, which is 1.273. In this calculator, λ is converted from nm to um, while f and D are both in mm, so the ratio between f and D is unitless and the result d is in um.

Practical warning

If a plano-convex lens is used at low f-number, spherical aberration can become significant. An aspheric lens or microscope objective usually improves small-f/# focusing.

If the beam diameter approaches the clear aperture, consider both spherical aberration and clipping carefully.

Ripple estimate

Ripple comes from clipping diffraction. When the Gaussian beam becomes large compared with the fiber/endcap aperture, the field at the aperture edge is no longer negligible. That edge field diffracts and interferes with the main beam.

I(r)=I0 exp(−2(rw)2)
E(r)=E0 exp(−(rw)2)
R=DfiberDbeam
ripple≈± 2 exp(−R2)

For a 400 um fiber/endcap diameter, a 250 um beam gives R = 1.6 and ripple about ±15-17%. A 175 um beam gives R = 2.29 and ripple about ±1%. This is an aperture-edge estimate, so it should be used as a practical design guideline rather than a full diffraction simulation.
